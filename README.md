# Statistical Analysis of Biological Data (R)

Collection of homework and analyses from a quantitative biology / statistics course, focused on real biological and medical datasets.

## Skills Demonstrated
- Data cleaning and exploratory analysis in R
- Statistical inference, confidence intervals, and hypothesis testing
- Regression, ANOVA, bootstrap, and permutation methods
- Visualization of biological data

## Key Analyses
- Heart disease risk factors
- Genetic recombination statistics
- Biological data modeling and distribution fitting
- Resampling techniques for inference

These exercises show applied statistical methods on biological data using R Markdown.
